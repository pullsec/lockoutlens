## about

LockoutLens is a CLI tool designed to audit Active Directory password policies and assess account lockout risks during authorized security testing.

It provides visibility into:

- domain password and account lockout policies
- Fine-Grained Password Policies (FGPP)
- account lockout state and authentication risk
- lockout-aware authentication testing conditions
- Active Directory account exposure

The tool is built for homelab, security research, and authorized assessment environments where understanding and controlling account lockout risk is critical.
